# Резерв220 — сайт з онлайн-підбором резервного живлення

Статичний сайт для GitHub Pages: каталог (43 товари з вивантаження Prom), картки товарів з описами та сумісністю, і майстер підбору системи за приладами, тривалістю відключень, фазністю, сонячними панелями та бюджетом.

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `reserve220`).
2. Завантажте в нього **вміст** цієї папки (`index.html`, `assets/`, `img/`, `tools/`, `.nojekyll`) — через **Add file → Upload files** або `git push`.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини сайт з'явиться за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Свій домен: **Settings → Pages → Custom domain**, і в DNS домену CNAME на `<ваш-логін>.github.io`.

## Назва та контакти

Усе в одному файлі — `assets/config.js`: назва магазину, телефон, Telegram, Viber, email, місто, години роботи. Порожнє значення ховає контакт.

## Оновлення цін і товарів

1. Вивантажте товари з Prom у .xlsx.
2. Виконайте: `python3 tools/update_products.py шлях/до/файлу.xlsx` (потрібен `pip install openpyxl`).
3. Завантажте оновлений `assets/products.js` у репозиторій.

Скрипт сам прибирає з описів блок «Чому PowerEnergy» і визначає категорію, потужність, ємність, напругу та фазність для підбору. Фото: якщо в `img/` є файл `<код-товару>-0.webp`, він має пріоритет; інакше береться посилання з таблиці.

## Як рахує підбір

- **Потужність інвертора:** одночасне навантаження (понад 3 кВт рахується з коефіцієнтом 0,6) × 1,2 запасу, з урахуванням пускового струму найбільшого приладу (інвертор тримає 2× номіналу кілька секунд).
- **Ємність батареї:** середнє споживання × години ÷ (0,8 глибина розряду × 0,9 ККД).
- **Варіанти:** готові комплекти + збірки «інвертор + N батарей» тільки з сумісною напругою (24 В / 48 В / HV). Для 3 фаз з великим навантаженням — лише трифазні інвертори.
- Параметри приладів (Вт, середнє споживання, пускові струми) — масив `APPS` в `assets/app.js`.
