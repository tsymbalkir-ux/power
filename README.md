# ENERGY SOLUTION — сайт з онлайн-підбором резервного живлення

Статичний сайт для GitHub Pages: каталог (43 товари з вивантаження Prom), картки товарів з описами та сумісністю, і майстер підбору системи за приладами, тривалістю відключень, фазністю, сонячними панелями та бюджетом.

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `reserve220`).
2. Завантажте в нього **вміст** цієї папки (`index.html`, `assets/`, `img/`, `tools/`, `.nojekyll`) — через **Add file → Upload files** або `git push`.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини сайт з'явиться за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Свій домен: **Settings → Pages → Custom domain**, і в DNS домену CNAME на `<ваш-логін>.github.io`.

## Назва, контакти, реквізити

Усе в одному файлі — `assets/config.js`: назва магазину, телефон, Telegram, Viber, email, адреса, графік, **реквізити продавця** (ФОП/ТОВ, ІПН/ЄДРПОУ, IBAN, банк), способи оплати й доставки, гарантійний строк. Незаповнені реквізити на сайті позначаються червоним «не вказано».

## Сторінки

- `index.html` — головна: онлайн-підбір, каталог, питання, контакти
- `oplata-dostavka.html`, `povernennya.html`, `garantiya.html`, `kontakty.html`, `oferta.html`, `privacy.html`

Шапка й підвал спільні (`assets/layout.js`). Тексти інформаційних сторінок — у `tools/build_pages.py`; після зміни виконайте `python3 tools/build_pages.py`. Юридичні тексти — типовий шаблон, бажано показати юристу.

## Аналітика та реклама

Ідентифікатори — у `assets/config.js` → `analytics` (порожнє значення = сервіс вимкнено). Код — `assets/analytics.js`, підключений у `<head>` усіх сторінок.

| Поле | Де взяти |
|---|---|
| `ga4` | Google Analytics → Адміністратор → Потоки даних → Ідентифікатор `G-…` |
| `googleAds` | Google Ads → Цілі → Конверсії → тег Google → `AW-…` |
| `adsLeadLabel`, `adsCallLabel` | Google Ads → конверсія → «Налаштувати тег» → у `send_to: 'AW-…/МІТКА'` частина після `/` |
| `clarity` | clarity.microsoft.com → Settings → Overview → Project ID |

Події GA4 / Clarity: `view_item` (відкрито товар), `begin_checkout` (натиснуто «Замовити»), `generate_lead` (сформовано заявку, конверсія Ads «Заявка»), `contact_click` (телефон / Telegram / Viber / email, конверсія Ads «Дзвінок»), `search`, `calc_start`, `calc_result`. У GA4 позначте `generate_lead` і `contact_click` як ключові події.

UTM-мітки та gclid запам'ятовуються в браузері й дописуються до тексту заявки рядком «Джерело: …» — менеджер бачить, звідки клієнт.

## Оновлення цін і товарів

1. Вивантажте товари з Prom у .xlsx.
2. Виконайте: `python3 tools/update_products.py шлях/до/файлу.xlsx` (потрібен `pip install openpyxl`).
3. Завантажте оновлений `assets/products.js` у репозиторій.

Скрипт сам прибирає з описів рекламний блок про продавця і визначає категорію, потужність, ємність, напругу та фазність для підбору. Фото: якщо в `img/` є файл `<код-товару>-0.webp`, він має пріоритет; інакше береться посилання з таблиці.

## Як рахує підбір

- **Потужність інвертора:** одночасне навантаження (понад 3 кВт рахується з коефіцієнтом 0,6) × 1,2 запасу, з урахуванням пускового струму найбільшого приладу (інвертор тримає 2× номіналу кілька секунд).
- **Ємність батареї:** середнє споживання × години ÷ (0,8 глибина розряду × 0,9 ККД).
- **Варіанти:** готові комплекти + збірки «інвертор + N батарей» тільки з сумісною напругою (24 В / 48 В / HV). Для 3 фаз з великим навантаженням — лише трифазні інвертори.
- Параметри приладів (Вт, середнє споживання, пускові струми) — масив `APPS` в `assets/app.js`.
